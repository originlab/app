Optimalen Versuchsplan auswählen

Select-Optimal-Design

Einführung

Das Auswählen eines optimalen Versuchsplans basiert auf der D-Optimalität und kann verwendet werden, um eine Fraktion der Versuchsdurchläufe auszuwählen, wobei die Gesamtanzahl der Versuche reduziert wird. Es kann auch einen vorhandenen Versuchsplan durch Hinzufügen von Versuchsdurchläufen erweitern, falls die Versuchsressourcen ausreichend sind.

Die Funktion ist nur verfügbar für

  • Allgemeinen vollfaktoriellen Versuchsplan
  • Wirkungsflächenversuchsplan
  • Mischungsversuchsplan

Verarbeitung

  • Bereiten Sie ein Arbeitsblatt vor, das Ihren Kandidatensatz enthält (oder erzeugen Sie eines über Versuchsplan erzeugen).
  • Wählen Sie Statistik: Qualitätsverbesserung: Versuchspläne DoE im Origin-Menü.
  • Wählen Sie das Symbol Optimalen Versuchsplan auswählen.
