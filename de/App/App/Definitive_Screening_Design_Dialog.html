Hilfreiche Informationen

Um den Dialog Definitiver Screening-Versuchsplan zu öffnen:

  • Wählen Sie Statistik: Qualitätsverbesserung: Versuchspläne DoE im Origin-Menü.
  • Wählen Sie das Symbol Versuchsplan erstellen und aus der Liste Definitiver Screening-Versuchsplan.

Verfügbare Versuchspläne anzeigen

Klicken Sie auf die Schaltfläche, um Informationen zu erhalten, wie Sie einen geeigneten Versuchsplan auswählen. Die Tabelle zeigt die Anzahl von Faktoren und Durchläufen.

Faktoren

Anzahl der stetigen Faktoren Legen Sie die Anzahl der stetigen Faktoren fest, die Sie in den Versuchsplan einbinden möchten.
Anzahl der kategorialen Faktoren Legen Sie die Anzahl der kategorialen Faktoren fest, die Sie in den Versuchsplan einbinden möchten.
Tabelle der stetigen Faktoren Ändern Sie ggf. den Faktornamen und legen Sie die niedrigen und hohen Stufen für jeden Faktor fest. Der einfache Versuchsplan enthält 1 Zentrakpunkt pro Replikation.
Tabelle der kategorialen Faktoren Wenn Sie mindestens 1 kategorialen Faktor ausgewählt haben, wird die Tabelle gezeigt. Geben Sie einen Textfaktor als entweder niedrig oder hoch ein.

Einstellungen

Anzahl der zusätzlichen Zentralpunkte Nur verfügbar, wenn es keine kategoriale Variable im Versuchsplan gibt.

Hinzufügen von zusätzlichen Zentralpunkte über 1 Zentralpunkt pro Replikation hinaus

Anzahl der Replikationen Wählen Sie die Anzahl der Replikationen. Die Replikationen sind mehrere Durchläufe mit den gleichen Faktoreinstellungen. Eine Replikation durchläuft jede Kombination einmal; zwei Replikationen durchläuft jede Kombination zweimal.

Das Hinzufügen von Replikationen kann die statistische Trennschärfe zum Erkennen von Effekten erhöhen, aber damit auch die Anzahl der Durchläufe insgesamt und die Kosten für die Ressourcen.

Block für Replikationen Durch Aktivieren dieser Option wird jede Replikation wie ein separater Block behandelt. Verwenden Sie sie, wenn Sie systematische Differenzen zwischen den Replikationssätzen vermuten und diese Effeke von den Faktoreffekten isolieren möchten.
Durchläufe randomisieren Randomisieren Sie die Ordnung aller Versuchsdurchläufe. Dies verteilt die Störfaktoren.
Zufallszahl Geben Sie eine nicht-negative ganze Zahl ein, um den Zufallszahlengenerator zu steuern.

Ausgabe

Versuchsplantabelle Die Versuchsplantabelle zeigt die Faktoreinstellungen für jeden Versuchsdurchlauf im Versuchsplan.
Kodierter Versuchsplan Verwenden Sie die Option, um den Versuchsplan in kodierten Einheiten (typischerweise –1, 0, +1) anzuzeigen, wobei –1 die niedrige Stufe, 0 den Zentralpunkt und +1 die hohe Stufe darstellen.

Dialogdesign

Speichern und laden Sie die Einstellungen des Dialogs. Verwenden Sie dies, um häufig verwendete Faktorkonfigurationen, Versuchsplanoptionen oder Ausgabeeinstellungen zu speichern, und rufen Sie sie für zukünftige Versuchspläne wieder auf, ohne alle Werte erneut einzugeben.
