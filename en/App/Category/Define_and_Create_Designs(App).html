2.42.2 Define and Create Designs

Define-Create-Designs


This chapter describes how to define and create experimental designs in the software. You can build a design from scratch using one of the standard design types, define a custom design to fit your specific requirements, or select an optimal subset of runs from an existing design.

Topics in this chapter:

  • Define Custom Designs - Define a design with your own factor settings and run structure.
  • Create Design
    • Definitive Screening Design - Create a design to screen many factors efficiently.
    • Factorial Design - Create a full or fractional factorial design.
    • Response Surface Design - Create a design to model curvature and optimize responses.
    • Mixture Design - Create a design for experiments where factors are components of a blend.
    • Taguchi Design - Create a robust parameter design using Taguchi methods.
  • Select Optimal Design - Select an optimal subset of runs from a candidate set.
