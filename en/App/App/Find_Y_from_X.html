2.42.3.2.3 Model Prediction - Find Y from X

DOE-Find-Y-from-X

The Find Y from X feature calculates predicted response values for selected factor settings using the fitted DOE model. It can be used to examine the predicted response at specific combinations of factor values without manually calculating the model equation.

The prediction results are generated in a DOEFindYfromX worksheet, which can be used to review and further analyze the predicted responses.


To perform Find Y from X

  1. In the Prediction tab of the analyze design dialog box , make sure Find Y from X is enabled
  2. A new worksheet named DOEFindYfromX is generated. Enter factor values into the respective columns; the response, its standard error, and interval bounds are calculated automatically.

The worksheet reports the following for each set of factor settings:

  • Predicted Y
    The model-estimated response at the specified factor settings
  • Standard Error
    The standard error of the predicted mean response.
  • 95% LCL / UCL
    Lower and upper confidence limits for the mean response. These bound the average outcome you would expect if the experiment were repeated many times at these settings.
  • 95% LPL / UPL
    Lower and upper prediction limits for an individual future observation.
