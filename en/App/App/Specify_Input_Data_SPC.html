Introduction

This chapter guides you through selecting measurement data, handling subgroup structures, and applying specification limits—such as Lower Specification Limit (LSL), Upper Specification Limit (USL), and Target values—across different data layouts for the SPC tools


Specifying Input Data

Select the options in Input tab of the dialog according to how your data arranged

Data Arrangement Options to specify
One dataset
  • Select All Subgroups in a Single Column radio box
  • Specify the data in columns as Measurement Data
  • Enter 1 in the Subgroup Size box
Note: If you have data with subgroups and each subgroup size are the same, you can also use this option and set a proper value for the Subgroup Size

All Subgroups in a Single Column
  • Select All Subgroups in a Single Column radio box
  • Specify the data in columns as Measurement Data
  • Specify the column with group info to be Subgroup Size Column'

Each Subgroup in a Separate Row

If the columns have different data size, right click on the row header of last row and select Set as End to push all the column having the same size

  • Select Each Subgroup in a Separate Row radio box
  • Specify data in multiple columns as Measurement Data
  • Select Subgroups Arranged in Rows Across Columns check box

Setting up Specifications and Parameters

Origin provides flexible methods for entering specification limits in the Input tab and the historic parameters in the Parameters tab

Single Variable

Enter a number
  • The value applies to all variables or groups
Enter values in header rows
  • The values stored in header rows are applied to the corresponding columns.


Enter name range and project variables

If you have defined named range or project variables for the specification limits or historic parameters, you can enter them directly into the specification fields.

Multiple Variables

The multiple variable tools in capability analysis supports following specication methods

Enter a number
  • The value applies to all variables or groups
Enter values in header rows
  • The values stored in header rows are applied to the corresponding columns.
Enter space-separated values
  • The values apply sequentially to each measurement column
Enter values in columns
  • The values stored in column are applied sequentially to each measurement column
